# The Possible and the Made

A methodological argument about what ceramic shape maps establish, supported by a recording-sensitivity study of archived Sue-ware point clouds. Geometric representation, production feasibility, historical occupation and surviving observation remain distinct.

[Read the paper](paper/PAPER.pdf) · [Manuscript](paper/PAPER.md) · [Study and reproduction](simulation/README.md)

October 2026 edition. Available in the [institute's papers catalog](https://piatra.institute/papers) and as a [direct PDF](https://piatra.institute/papers/the-possible-and-the-made.pdf). Publication does not indicate external peer review.
